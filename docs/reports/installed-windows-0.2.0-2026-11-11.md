## Operating limits and documentation scope

This is an unsigned Windows portable application for one trusted OS owner. Workspace data is local
plaintext, with no hosted account isolation, encryption or protection from malicious concurrent
same-account modification. Hashes identify bytes; source assertions do not authenticate an author or
approve real procedures. There is no external AI or live equipment interface. Synthetic retrieval,
comparison and automated accessibility measurements do not establish universal applicability,
semantic equivalence, exhaustive accessibility conformance or clean-machine installation safety.

This documentation-only update preserves runtime, version, source locks, all original gates,
historical Office binaries and published release assets. Its own exact-source hosted checks and
processed security analysis remain separate required publication checks.
